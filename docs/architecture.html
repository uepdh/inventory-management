Factory Inventory Management System

System architecture, tech stack, and data flow overview

Tech Stack

Frontend

Vue 3 + Vite

  • Vue 3.4 (Composition API)
  • Vue Router 4.3 (client-side routing)
  • Axios 1.6 (HTTP client)
  • Vite 5.2 (dev server / bundler)
  • Port: 3000
Backend

Python + FastAPI

  • FastAPI 0.110+ (REST API)
  • Pydantic 2.5+ (validation)
  • Uvicorn (ASGI server)
  • Managed with uv
  • Port: 8001
Data

In-memory JSON

  • No database
  • JSON files in server/data/
  • Loaded once at startup by mock_data.py
  • Resets on server restart

Request Data Flow

1
User adjusts filters The top FilterBar and page-level UI update reactive state (warehouse, category, status, month) held in the useFilters composable.
2
Vue view calls the API client A view (e.g. Dashboard.vue) calls a function in client/src/api.js, passing the current filters.
3
Axios builds the request Non-"all" filters are appended as query params and sent via axios.get() to http://localhost:8001/api/....
4
FastAPI routes the request server/main.py matches the endpoint and passes query params into shared helpers apply_filters() / filter_by_month().
5
In-memory data is filtered Filters run against Python lists/dicts already loaded from JSON by mock_data.py — no database round-trip.
6
Response is validated & returned Results are coerced through Pydantic response_models (e.g. InventoryItem, Order) and serialized to JSON.
7
Vue renders the update The response is stored in a ref; computed properties derive chart/table data and the template re-renders reactively.
